# Telegram Clicker Game

Игра-кликер внутри Telegram, разработанная с использованием Python и HTML/JS.

## Функционал:
- Начисление очков за клик (с анимацией).
- Магазин улучшений (сила клика, пассивный доход, крит. шанс).
- Автосохранение прогресса.
- Отправка результата в Telegram-бота.

## Технологии:
- Python (Aiogram 3)
- HTML / CSS / JavaScript
- Telegram WebApp API
